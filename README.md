# 設備掃描借用／歸還系統

以手機掃描 QR Code 借用與歸還設備，狀態與紀錄即時寫入 Google Sheet，並提供一個狀態總覽網頁。

---

## 1. 系統架構

```
┌──────────────┐  掃描 QR Code   ┌──────────────┐   HTTP GET    ┌──────────────────┐
│ 手機瀏覽器    │ ─────────────▶ │ index.html   │ ────────────▶ │ Google Apps      │
│ (GitHub Pages)│                │ 掃描借還頁    │   ?id&action  │ Script (Code.gs) │
└──────────────┘                └──────────────┘               └────────┬─────────┘
                                                                        │ 讀寫
┌──────────────┐  每 10 秒輪詢  ┌──────────────┐   HTTP GET             ▼
│ 手機／電腦    │ ─────────────▶ │ status.html  │ ────────────▶ ┌──────────────────┐
│ 瀏覽器        │                │ 狀態總覽頁    │  ?action=list │ Google Sheet     │
└──────────────┘                └──────────────┘  ?action=log  │ Equipment_List   │
                                                               │ 借還紀錄          │
                                                               └──────────────────┘
```

| 層級 | 技術 | 部署位置 |
|---|---|---|
| 前台 | HTML + JavaScript + html5-qrcode | GitHub Pages |
| 後台 | Google Apps Script（網頁應用程式） | Google 雲端 |
| 資料庫 | Google Sheet | Google 雲端 |
| QR Code | quickchart.io 免費 API，由 Sheet 公式產生 | Google Sheet 儲存格 |

---

## 2. 檔案說明

| 檔案 | 用途 |
|---|---|
| `index.html` | 掃描頁。選擇借用或歸還模式，掃 QR Code 後呼叫後台更新狀態。 |
| `status.html` | 總覽頁。顯示所有設備狀態、統計數字與最近借還紀錄，自動更新。 |
| `Code.gs` | 後台。接收前台請求，讀寫 Google Sheet。 |
| `README.md` | 本文件。 |

## 3. Google Sheet 結構

### 3.1 `Equipment_List` 分頁（需手動建立）

| 欄 | 欄名 | 說明 |
|---|---|---|
| A | 設備編號 | 唯一值，建議 4 碼數字，例如 `1001`。QR Code 內容即為此值。 |
| B | 名稱 | 例如 `數位相機` |
| C | 狀態 | 只能是 `可借用` 或 `借出中`，由程式自動更新 |
| D | （保留） | 程式不讀取，可自由使用 |
| E | 廠牌 | 例如 `Canon` |
| F | QR Code | 公式產生，見 3.3 |

第一列為標題列，程式從第二列開始讀取。

### 3.2 `借還紀錄` 分頁（程式自動建立）

第一次借用或歸還成功時自動建立，不需手動新增。

| 欄 | 欄名 | 說明 |
|---|---|---|
| A | 時間 | 格式 `yyyy/MM/dd HH:mm:ss` |
| B | 設備編號 | |
| C | 名稱 | |
| D | 廠牌 | |
| E | 動作 | `借用` 或 `歸還` |
| F | 更新後狀態 | `借出中` 或 `可借用` |

### 3.3 QR Code 產生公式

在 `Equipment_List` 的 F2 輸入後往下填滿：

```
=IMAGE("https://quickchart.io/qr?text=" & A2 & "&size=250&margin=2")
```

QR Code 內容只有編號本身。前台若掃到完整的 quickchart 網址，也會自動擷取 `text=` 後的編號。

## 4. 後台 API（Code.gs）

所有請求皆為 HTTP GET，網址為 Apps Script 的「網頁應用程式網址」。

### 4.1 借用

```
GET {API_URL}?id=1001&action=borrow
```

| 條件 | 回應（純文字） | Sheet 變化 |
|---|---|---|
| C 欄為「可借用」 | `借用成功！\n{廠牌} {名稱}\n狀態已更新為：借出中` | C 欄改為「借出中」，紀錄分頁新增一列 |
| C 欄不是「可借用」 | `借用失敗！該設備目前狀態為：{狀態}` | 無 |
| 編號不存在 | `找不到設備編號：{id}` | 無 |

`action` 省略時預設為 `borrow`。

### 4.2 歸還

```
GET {API_URL}?id=1001&action=return
```

| 條件 | 回應（純文字） | Sheet 變化 |
|---|---|---|
| C 欄為「借出中」 | `歸還成功！\n{廠牌} {名稱}\n狀態已更新為：可借用` | C 欄改為「可借用」，紀錄分頁新增一列 |
| C 欄不是「借出中」 | `歸還失敗！該設備目前狀態為：{狀態}（未在借出狀態）` | 無 |
| 編號不存在 | `找不到設備編號：{id}` | 無 |

### 4.3 設備清單

```
GET {API_URL}?action=list
```

回應 JSON：

```json
{
  "updatedAt": "2026/10/30 14:05:30",
  "items": [
    { "id": "1001", "name": "數位相機", "status": "可借用", "brand": "Canon" },
    { "id": "1002", "name": "三腳架",   "status": "借出中", "brand": "Manfrotto" }
  ]
}
```

A 欄空白的列會略過。

### 4.4 借還紀錄

```
GET {API_URL}?action=log&limit=50
```

`limit` 省略時為 50。回應 JSON，由新到舊排列：

```json
{
  "records": [
    { "time": "2026/10/30 14:05:30", "id": "1004", "name": "投影機",
      "brand": "Epson", "action": "借用", "status": "借出中" }
  ]
}
```

紀錄分頁不存在或沒有資料時回傳 `{ "records": [] }`。

### 4.5 函式一覽

| 函式 | 說明 |
|---|---|
| `doGet(e)` | 進入點。依 `action` 分派到查詢或借還邏輯。 |
| `jsonOutput(obj)` | 把物件轉成 JSON 回應，並設定 MIME 類型。 |
| `getEquipmentList()` | 讀取 `Equipment_List`，整理成物件陣列。 |
| `getLog(limit)` | 讀取 `借還紀錄` 最後 `limit` 列，反轉成新到舊。 |
| `appendLog(ss, id, name, brand, action, status)` | 寫一列紀錄。分頁不存在時建立、寫標題、粗體、凍結第一列。 |
| `formatTime(d)` | 以專案時區格式化日期。 |

### 4.6 常數

| 常數 | 預設值 | 說明 |
|---|---|---|
| `LIST_SHEET_NAME` | `Equipment_List` | 設備清單分頁名稱 |
| `LOG_SHEET_NAME` | `借還紀錄` | 紀錄分頁名稱 |

若分頁改名，改這兩個常數即可。

## 5. 前台：掃描頁（index.html）

### 5.1 畫面元件

| 元件 | id | 說明 |
|---|---|---|
| 借用按鈕 | `btn-borrow` | 切換為借用模式，藍色為選取中 |
| 歸還按鈕 | `btn-return` | 切換為歸還模式，綠色為選取中 |
| 模式提示 | `mode-hint` | 顯示目前模式與掃描後的狀態變化 |
| 總覽連結 | （class `status-link`） | 在新分頁開啟 `status.html` |
| 鏡頭選單 | `camera-select` | 列出裝置所有鏡頭，切換後重新啟動掃描 |
| 掃描區 | `reader` | html5-qrcode 的相機畫面 |
| 結果區 | `result` | 顯示處理中、成功（綠）、失敗（紅）訊息 |

### 5.2 流程

1. 頁面載入後向瀏覽器要求鏡頭清單，預設啟動第一個鏡頭。
2. 掃到 QR Code 時，若 `isProcessing` 為 true 則忽略，避免同一張連續觸發多次。
3. 若內容包含 `text=`，擷取其後的編號；去除前後空白。
4. 組合網址 `{API_URL}?id={編號}&action={currentMode}`，`currentMode` 為 `borrow` 或 `return`。
5. 顯示回應文字。含「成功」為綠色，否則紅色。
6. 3.5 秒後清除訊息並解除 `isProcessing`，可掃下一張。

### 5.3 可調整參數

| 位置 | 預設值 | 說明 |
|---|---|---|
| `API_URL` | （GAS 網址） | 後台網址，須與 `status.html` 相同 |
| `config.fps` | 10 | 每秒辨識次數 |
| `config.qrbox` | 250×250 | 掃描框大小 |
| `setTimeout` 延遲 | 3500 毫秒 | 掃描成功後的冷卻時間 |

## 6. 前台：總覽頁（status.html）

### 6.1 畫面元件

| 區塊 | 說明 |
|---|---|
| 工具列 | 最後更新時間、「立即更新」按鈕、「每 10 秒自動更新」勾選框 |
| 統計卡片 | 設備總數、可借用數（綠）、借出中數（紅） |
| 設備清單 | 搜尋框（編號、名稱、廠牌）、狀態篩選、表格 |
| 最近借還紀錄 | 最近 50 筆，新到舊，借用藍字、歸還綠字 |

手機寬度（480px 以下）會隱藏廠牌欄與更新後狀態欄。

### 6.2 流程

1. 載入時呼叫 `loadAll()`，同時發出 `?action=list` 與 `?action=log` 兩個請求。
2. 回應後更新統計、清單、紀錄。
3. 若自動更新勾選中，每 10 秒重複一次。
4. 任一請求失敗時，在 `error` 區顯示「讀取資料失敗」，不清除原有畫面。

### 6.3 可調整參數

| 位置 | 預設值 | 說明 |
|---|---|---|
| `API_URL` | （GAS 網址） | 後台網址 |
| `LOG_LIMIT` | 50 | 顯示的紀錄筆數 |
| `setInterval` 間隔 | 10000 毫秒 | 自動更新間隔 |

## 7. 部署摘要

完整步驟見對話紀錄，重點如下：

1. **後台**：Google Sheet >「擴充功能」>「Apps Script」，貼上 `Code.gs`，儲存。
2. **發布**：「部署」>「管理部署」> 編輯 > 版本選「新版本」> 部署。只儲存不會生效。
3. **檢查網址**：`index.html` 與 `status.html` 的 `API_URL` 須與發布的網址一致。
4. **前台**：兩個 html 上傳到 GitHub 專案，開啟 GitHub Pages，等 1 到 3 分鐘。
5. **測試**：借用一台、看總覽頁、歸還同一台、確認紀錄分頁有兩列。

## 8. 常見問題

| 症狀 | 原因 | 處理 |
|---|---|---|
| 掃描後「系統連線錯誤」 | `API_URL` 錯誤或後台未發布 | 檢查網址，重新發布新版本 |
| 總覽頁「讀取資料失敗」 | 後台仍是舊版，沒有 `list` | 發布新版本 |
| 歸還永遠失敗 | GitHub 上仍是舊的 `index.html` | 重新上傳 |
| 紀錄時間差 8 小時 | Apps Script 時區 | 左側「專案設定」> 時區「Asia/Taipei」 |
| 相機打不開 | 未授權或非 https | 允許相機權限，確認網址為 https |
| 找不到設備編號 | A 欄值與 QR Code 不一致 | 檢查是否有空白或儲存格被當成數字格式 |

## 9. 已知限制與可擴充方向

- 無身分驗證。任何知道網址的人都能借還，適合校內或小團隊使用。
- 未記錄借用人。可在前台加輸入框，後台多傳一個參數並寫入紀錄分頁 G 欄。
- 同一秒內兩人掃同一台設備，理論上可能都成功。可在後台加 `LockService` 避免。
- 總覽頁以輪詢更新，設備數上千時可拉長間隔或改為手動更新。
- 狀態值固定為「可借用」與「借出中」。若需「維修中」等狀態，需同時修改後台判斷與總覽頁的標籤樣式。
